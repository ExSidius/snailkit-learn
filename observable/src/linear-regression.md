# Linear Regression

A simple supervised learning algorithm for predicting continuous values.

## How do you fit a line?

It's a deceptively deep question. Let's say you have a set of points that looks like this:

Not the worst, but it's pretty arbitrary.

This problem comes up a lot.

It was first solved by Adrien-Marie Legendre in 1805, but I use the word solved extremely loosely. He solved it with "The Method of Least Squares".

Since then, Linear Regression has been tackled by Carl Friedrich Gauss, Pierre-Simon Laplace, Francis Galton, Karl Pearson, Andrey Markov, Ronald Fisher, and many others in the modern era.

Each of them have contributed to the algorithm, the implementation, the optimization, and the interpretation.

We'll explore all of these details.

Legendre and Gauss both independently came up with the method of least squares, which is the basis of linear regression.

The essential idea is that you find the line that minimizes the sum of the squared distances between the points and the line.

That is to say, if you imagine that these points were generated by some linear function (where linear in this case simply means producing a line) and then some random noise was added to each point, then the line you fit will be the one that minimizes the average squared error.

> [Scatter plot with the best-fit line and error lines would appear here.]

Let's state this a little more formally.

Legendre and Gauss decided to minimize the sum of the squared errors.

**Squared Errors:**

```tex
\sum_{i=1}^{n} (y_i - \hat{y}_i)^2
```

Where:

- ${tex`y_i`} is the actual value
- ${tex`\hat{y}_i`} is the predicted value from our line

This immediately raises a question - why *squares* in particular?

Let's outline a few alternatives.

**Absolute Errors:**

```tex
\sum_{i=1}^{n} |y_i - \hat{y}_i|
```

**Cubed Errors:**

```tex
\sum_{i=1}^{n} (y_i - \hat{y}_i)^3
```

**Quartic Errors:**

```tex
\sum_{i=1}^{n} (y_i - \hat{y}_i)^4
```

So why least squares?

Well, let's start with the trivial - we're trying to minimize something. Minimizing means differentiating, and finding where the derivative equals 0. That's the game you have to play when you're minimizing.

So we have an infinite universe of lines to choose from, lines that could fit our data. We're choosing the one that minimizes our error term (in this case, the squared error term).

The general formula of a line is:

```tex
y = mx + b
```

Our points are ${tex`\hat{y}`}. 

So we're trying to find the ${tex`m`} and ${tex`b`} that make it so that ${tex`(\hat{y} - (mx + b))^2`} is minimized.

Nice thing about the fact that ${tex`m`} and ${tex`b`} are our only two free terms is that we can visualize it.
