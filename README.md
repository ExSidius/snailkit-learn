# 🐌 snailkit-learn

> A slow, useless, but highly educational machine learning and deep learning library implemented in pure Python.  
> Built for understanding, not performance.

---

## ✨ Why?

Most ML libraries hide the math and implementation details behind C extensions and vectorized black boxes.  
**`snailkit-learn`** is different: it teaches you how things work by being deliberately slow and transparent.

You won’t ship this in production — but you *will* deeply understand the fundamentals of modern machine learning.
